# 03 · 理论基础：八个图式

## 3.1 为什么选图式疗法

Jeffrey Young 的图式疗法（Schema Therapy）提出「早期不适应图式」（Early Maladaptive Schema, EMS）——在童年形成、贯穿一生、在亲密关系中反复自动激活的深层信念与情绪模式。

选它作为主理论的原因：

1. **它建模的是信念，不是行为。** 这正是产品要抓的东西——行为可以千变万化，底层信念是那条贯穿的线。
2. **它天然带成因。** 每个图式都有童年来源，这直接支撑了"给模式一个正当的出身"（见 [`02-设计原则.md`](02-设计原则.md) 2.2.1）。
3. **它有应对方式的概念。** 同一个图式在不同应对方式下长出完全不同的人，这提供了必要的输出分辨率。

> **重要声明**：本产品**只学习图式疗法的理论**。所有测评题目为完全原创，不使用、不翻译、不改写 YSQ（Young 图式问卷）或任何受版权保护的量表条目。

## 3.2 八个图式总览

从 Young 的 18 个图式中，选取与恋爱关系最相关的八个。**此清单已锁定，不再增减。**

| 编号 | 名称 | 核心信念（一句话） |
|---|---|---|
| SCH1 | 缺陷 / 羞耻 | 我本质上是有缺陷的，一旦被看清就会被嫌弃 |
| SCH2 | 遗弃 / 不稳定 | 重要的人最终都会离开我 |
| SCH3 | 情感剥夺 | 没有人会真正理解我、回应我的情感需要 |
| SCH4 | 不信任 / 受伤 | 别人最终会用某种方式伤害、利用、欺骗或背叛我 |
| SCH5 | 服从 | 如果我表达自己的需求或情绪，会带来冲突或惩罚，所以必须把自己压下去 |
| SCH6 | 自我牺牲 | 我必须把对方放在自己之前，否则我会愧疚、会觉得自己自私 |
| SCH7 | 纠缠 / 未发展的自我 | 我没有一个独立于关系而存在的"自我" |
| SCH8 | 苛刻标准 / 过度苛责 | 我和我的伴侣、我的关系必须达到极高标准，否则就是不可接受的 |

> **命名待统一**：文档历史版本中 SCH7 曾写作「纠结」（应为「纠缠」，Enmeshment），SCH8 曾写作「性别标准/过度虐待」（转写错误，应为「苛刻标准/过度苛责」，Unrelenting Standards / Hypercriticalness）。以本表为准。

## 3.3 每个图式的八个行为面向

每个图式向下拆成 8 个可观察的行为面向。**这是产品目前分辨率的主要来源：8 图式 × 8 面向 = 64 种可区分的配置。**

### SCH1 · 缺陷 / 羞耻
1. 不敢主动追求：怕暴露真实的自己后被拒绝
2. 过度自我贬低：在关系里过度害怕对方发现自己不值得
3. 用外部条件补偿：拼事业 / 学历 / 外貌来补"不配感"
4. 对真正喜欢自己的人失去兴趣："他喜欢我，说明他眼光不行"
5. 关系稳定期反而焦虑：等待对方发现真实自己的那一刻
6. 选择条件低于自己的对象：那样安全，不会被放弃
7. 恐惧亲密暴露：靠近就意味着会被看穿
8. 隐性自我攻击：表面坦然，内心反复贬低自己

### SCH2 · 遗弃 / 不稳定
1. 过度警觉：晚回消息就坐立不安、反复刷对方社交媒体
2. 关系正盛时的预演性焦虑：关系还好时已在想"他什么时候会变心"
3. 不断索取确认：反复试探，但任何回答都得不到长久安心
4. 对独立性的恐惧：对方一表现出独立就感到威胁
5. 测试性行为：故意冷淡、说分手，看对方反应
6. 悖论性吸引：对安稳型伴侣没感觉，对让自己患得患失的特别上头
7. 创伤反刍：反复回忆每一个可能预示分手的细节
8. 承诺执着：签字画押式的安全感需求

### SCH3 · 情感剥夺
1. 表达压抑："我说了他也不会懂"，所以不说
2. 需求否认：觉得自己的情感需求"太多""不应该有"
3. 回避被照顾：对方表达情感时觉得不真实、想躲
4. 选择低情商伴侣：选不善表达的人，然后抱怨对方不懂自己
5. 过度付出循环：总觉得自己是付出更多的那个
6. 深夜孤独：哪怕在关系中也常常独自 emo
7. 照顾别人代偿：把照顾别人当成获得连接的方式
8. 拒绝被照顾：对"被照顾"感到不适应，下意识拒绝

> **SCH3 有三个亚型**：A 滋养剥夺（没被温柔照顾过）/ B 共情剥夺（没被真正理解过）/ C 保护剥夺（没被强有力保护过）。中国 25–32 岁女性中 B 型占比最高。

### SCH4 · 不信任 / 受伤
1. 动机怀疑：反复怀疑对方"是不是图我什么"
2. 隐藏脆弱：脆弱会成为日后被攻击的把柄
3. 保留逃跑通道：不合财、不全心投入、保留备选
4. 过度核查：反复检查对方的手机、社交账号、行踪
5. 承诺怀疑：觉得说什么都不算数
6. 敌意归因：把中性行为解读为有敌意
7. 先发制人：在被伤害之前先冷淡、先攻击、先结束
8. 创伤泛化：把前任的伤害泛化到所有人

> **SCH4 另有「创伤来源类型」字段**（7 种）：前任出轨 / 被 PUA / 原生家庭背叛 / 亲密关系外的背叛 / 相亲功利性接近（本土特征）/ 青春期创伤 / 来源不明。

### SCH5 · 服从
1. 需求消音：长期说"随便""你定"，久而久之连自己都不知道想要什么
2. 不敢拒绝：几乎从不说"不"，事后憋屈
3. 愤怒压抑：明明生气却不敢表达
4. 决策让渡：把关系里大小决定权都交给对方
5. 冲突回避型顺从：一感觉对方要不高兴，立刻退让道歉
6. 预判服从：不等对方开口就提前揣摩并照做
7. 隐性怨恨累积：怨恨以冷战、拖延、被动攻击形式渗出
8. 服从后失真：长期顺从导致自我感模糊

> **SCH5 有两个亚型**：需求服从型 / 情绪服从型（后者更隐蔽，常被当成"我脾气好"）。

### SCH6 · 自我牺牲
1. 过度照顾 / 情绪保姆
2. 预判式付出
3. 习惯性压抑自己的需求
4. 隐性怨恨累积（是委屈，不是愤怒）
5. 以"被需要"确认价值
6. 吸引索取型 / 需要被拯救的伴侣（拯救者情结）
7. 拒绝 / 无法接受被照顾
8. 燃尽与突然抽离

### SCH7 · 纠缠 / 未发展的自我
1. 融合渴望："我们要合二为一"
2. 自我认同消失：一谈恋爱就弄丢自己
3. 无法忍受分离 / 独处即空虚
4. 没有独立的喜好和主张
5. 过度卷入对方的情绪与生活
6. 原生家庭的纠缠延续
7. 以关系定义存在价值
8. 窒息式亲密反噬：太黏反而把对方逼走

### SCH8 · 苛刻标准 / 过度苛责
1. 完美伴侣清单 / 严苛评判标准
2. 对伴侣缺点零容忍 / 过度挑剔
3. "他不是对的人"灾难化
4. 对关系本身的完美主义
5. 自我苛求 / 必须做完美女友
6. 持续的不满足与紧绷
7. 比较与向上看
8. 难以为"足够好"停留 / 错过型反噬

## 3.4 应对方式（关键维度）

图式疗法认为，同一个图式在不同应对方式下会长出**完全不同的人**。本产品在数据层已强制标注四类：

| 应对方式 | 含义 |
|---|---|
| **屈从型** | 直接活出图式信念 |
| **逃避型** | 回避会触发图式的情境 |
| **过度补偿型** | 用反向行为掩盖图式 |
| **健康反应** | 识别情绪、直接沟通、不做条件反射行为（较少但很有价值） |

**为什么这个维度关键**——以 SCH1 为例，三种应对方式长出三个完全不同的人：

| | 表现 |
|---|---|
| SCH1 + 屈从 | 找看不起自己的人，接受被贬低，"我本来也配不上更好的" |
| SCH1 + 回避 | 不敢深入，一到要暴露自己就撤，宁可不开始 |
| SCH1 + 过度补偿 | 用收入、成就、外形把自己武装到牙齿，绝不示弱 |

[`01-背景与设计原点.md`](01-背景与设计原点.md) 里那个案例，是 **SCH1 + 过度补偿（强调经济）+ 回避（避讳腿）**。

**这个维度的产品意义**：
- 图式几乎不动，**应对方式是能松动的**——这是干预的落点
- 图式是"你六岁学到的东西"（不可指责），应对方式是"你今天还在做的事"（可指认、可改）
- 输出空间从 8 变成 24–32，报告的独特性大幅提升

> **当前状态**：应对方式在**数据标注层已完成**，但**是否作为算法输出维度和报告正式模块，尚未决定**。

## 3.5 易混图式的辨析规则

采集与标注阶段已建立成熟的辨析规则。**这些规则同时是设计鉴别题的现成蓝本**（同一情境、不同内心独白）。

| 表层行为 | 内心独白 → 归属 |
|---|---|
| 查岗 / 查手机 | "他是不是不爱我了、要走了" → **SCH2**<br>"他是不是在骗我、图我什么" → **SCH4** |
| 故意冷战 / 破坏关系 | "看他爱不爱我、会不会留下" → **SCH2**（测试性行为）<br>"防备他伤害我、先下手为强" → **SCH4**（先发制人） |
| 压抑自己、迁就对方 | "我不敢、我怕" → **SCH5**<br>"我不忍心、停不下来地给" → **SCH6** |
| 黏、离不开对方 | "怕他走" → **SCH2**<br>"我自己应付不来" → 依赖（**不在八个图式内**）<br>"我没有自己了、不知道自己喜欢什么" → **SCH7** |
| 出现"不够好"三个字 | "怕自己不够好、配不上、被嫌弃" → **SCH1**<br>"嫌他不够好、达不到我的标准" → **SCH8** |
| 在一起也孤独、他不懂我 | → **SCH3** |

### 已知的两个"幽灵去处"

辨析规则中出现了两个八图式之外的归属：**依赖 / 无能**（见 SCH7 辨析）和**寻求认可**（见 SCH5 辨析）。这两个池子不存在，命中这两类的素材目前无处安放。

**处置方案（待定）**：已确定不新增图式。备选方案是（a）弃用，（b）并入相邻图式（倾向把「寻求认可」并入 SCH1，因其底层往往是"我本身不够好，得靠表现换认可"），（c）建立「未归类」桶做观测。

## 3.6 图式之间的高相关性

以下图式对高度相关，会同涨同落：

- SCH2 遗弃 ↔ SCH4 不信任
- SCH5 服从 ↔ SCH6 自我牺牲
- SCH1 缺陷 ↔ SCH3 情感剥夺
- **SCH1 缺陷 ↔ SCH8 苛刻标准**（尤其重要：很多人用"高标准、挑剔"来过度补偿底层的不配得感——这正是旗舰案例的结构）

这意味着算法排出的 top3 很可能是一个相关簇，"从中挑出最契合的那一个"可能挑的是噪声。**交付形态倾向于「主图式 + 次图式 + 应对方式」，而非单一图式。**
